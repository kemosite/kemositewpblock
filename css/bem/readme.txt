BEM stands for Block Element Modifier, a popular CSS naming convention
developed by the search engine company Yandex to organize, maintain, and scale
front-end code.  It divides user interfaces into independent blocks (standalone
entities like headers or menus), elements (parts of blocks with no standalone
meaning like menu items), and modifiers (flags that change appearance or
behavior such as disabled or highlighted).  This methodology uses a strict
naming structure of block__element–modifier (e.g., .button--primary) to ensure
code is reusable, readable, and free from naming conflicts.
